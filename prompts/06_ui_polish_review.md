# Prompt: UI Polish Review

```text
Review this interface as a senior product designer for a public-interest research product.

Goals:
- Visually impressive but restrained.
- Credible, readable, and source-transparent.
- Avoid generic AI/SaaS aesthetics: no excessive gradients, no glassmorphism, no glowing orbs.
- Prioritize hierarchy, spacing, typography, and source trust.

Output:
1. Top 10 design issues
2. Specific fixes
3. Revised layout plan
4. Components to add/remove
5. Accessibility issues
6. Mobile improvements
7. Copy/microcopy improvements
```
