# Prompt: Local-Language Query Generator

```text
Generate local-language search queries for researching [ENTITY/COUNTRY/CLUSTER] for an AI safety/governance atlas.

Return:
- Local-language name variants
- Acronym variants
- Official source domain targets
- 20 search queries in the local language
- 10 English-language cross-check queries
- Ambiguous terms and translation warnings
- Likely source types to prioritize

Do not research the answer yet. Only produce a search plan.
```
